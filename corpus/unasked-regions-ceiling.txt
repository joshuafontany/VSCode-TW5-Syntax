# Regions whose end can never break on a line, and that no cut in this corpus ever leaves open.
# The count may fall and may never rise.
#
# 98 regions carry no line bound. That number alarms and means little on its own: 77 of them stand
# open across a blank line under some cut and AGREE with the parser, because TiddlyWiki carries
# those constructs too — a `"""` attribute value spans blank lines, a definition body runs to its
# `\end`, an element with no closer reaches the end of the tiddler. Standing open names no defect.
# Disagreeing does, and the ledger beside this file holds those.
#
# This count answers COVERAGE instead. A region no specimen opens stands unasked rather than safe,
# and the two read alike from outside: a green gate. Measured with 800
# upstream TiddlyWiki tiddlers added to the sweep, twelve more regions come open — so this corpus
# under-covers its own grammar by a knowable amount, and the number below names the residue.
#
# THE COUNT WANTS COLLIDING BEFORE IT MEANS ANYTHING. A grammar spells the line bound five ways —
# `$`, `(?=$)`, `^$`, `|$`, `(?=$|…)` — and a reader naming it by shape catches one and files the
# rest as debt. Six inline emphasis rules end `(?=$)` and open only where a closer stands later on
# the same line; the paragraph rule spells `^$` with no lookahead around it. Reading by shape puts
# twenty such regions among the runaways. So the reader walks the pattern for a dollar standing as
# an ANCHOR, and skips one escaped or sitting in a character class — every widget rule carries `\$`
# for the tag prefix, and the typed block spells `\$\$\$`.
#
# WHAT A SPECIMEN CAN REACH, AND WHAT NO SPECIMEN CAN. A region wants a specimen carrying its
# construct across a line break, and `spans.multiline.tw` and `pragmas.signatures.tw` hold them:
# quoted, triple-quoted, bracketed, variable and substituted attribute values; a widget attribute
# holding a filter, an indirect reference or a variable; a pragma signature in every default
# quoting the grammar carries a region for; a `\parameters` directive; an inline call; an XML
# processing instruction; a script under a type no grammar claims; an element name no grammar
# claims inside math. Seated at 21 on 2026-09-09, down from 44 — the constructs above account for
# the 23 that closed. That 44 itself fell from an earlier 62, closing every construct that spans a
# line break — a pragma signature, a macro argument, quoted and triple-quoted attribute values, a
# character-data payload, a comment inside embedded JavaScript — each one CLOSED so containment
# holds while an intermediate line end sits inside the region; scope coverage rose from 467 to 469
# over the same change.
#
# THE COUNT ALSO NEEDED COLLIDING BEFORE READING BY SHAPE MEANT ANYTHING: a naive reading counted
# 118 unbounded and 79 unasked where 98 and 62 stood once the reader walked the pattern for a
# dollar standing as an ANCHOR rather than by shape alone. `tools/grammar-scopes.test.js` carries
# the control that provokes a literal `\$` — carried by every widget rule and by the typed block's
# `\$\$\$` — directly, to keep it naming no bound.
#
# THE RESIDUE, RE-MEASURED 2026-09-09 UNDER THREE SENTINELS. The sweep ran three times over the
# same 906 cuts, appending a quoteblock (`<<<`), a typed block (`$$$text/plain`) and a style block
# (`@@`) in turn, and collected the scopes standing at the sentinel's own line each time. The
# quoteblock run reproduces 21 exactly, which is the control: the reading below comes off the same
# instrument that seats the ceiling.
#
#   21 unasked under the quoteblock · 14 under a typed block · 15 under a style block · 14 under
#   the union of all three.
#
# SEVEN ENTRIES COME OPEN THE MOMENT THE SENTINEL STOPS COLLIDING, and no more. Every transclusion
# rule ends `(\}\})|(?=^(?:!|\*|#|;|:|>|<<<|\||---|\\))` — `<<<` stands in that alternation, so
# the region closes on the line the probe reads and the instrument cannot ask it at all. The seven:
# `meta.transclusion.filteredtranscludeblock`, the two `meta.filter` regions (one under
# `filteredtranscludeblock`, one under `filteredtranscludeinline`), the two
# `meta.transclusion.tokenize` regions and the two `meta.transclusion.text-reference` regions (one
# each under `transcludeblock` and `transcludeinline`). The text-reference regions carry no `<<<`
# in their own end — `(?=\|\||\}\})` — and come open because the enclosing close pops them.
#
#   TRACED, ONE SPECIMEN: `corpus/wikitext/inline.transclusions.tw:25`, cut after `{{{ [tag[Done]]`.
#   Under a typed-block sentinel the sentinel's line reads `$$$text/plain` and wears
#   `meta.transclusion.filteredtranscludeblock` · `meta.filter` · `meta.filter.run` ·
#   `entity.filter.operator.title` · `string.unquoted`. Under the quoteblock sentinel NO cut in the
#   corpus opens that region, and the control holds for all three traced names.
#
# THE EARLIER READING NAMED THE WRONG MEMBERS. It counted seven and called them "the inline
# transclusion, the filtered pair, and the text reference and filter regions nested inside them".
# Measured, the two OUTER inline regions — `meta.transclusion.filteredtranscludeinline` and
# `meta.transclusion.transcludeinline` — stay unasked under every sentinel tried, while the block
# spelling and the nested regions come open. An outer inline region wants a cut standing INSIDE a
# line, and this probe cuts at line boundaries only.
#
# AND THE INSTRUMENT CANNOT TELL TWO OF THEM APART. `unboundedRegions` matches a region by the
# SCOPE NAME it declares, and `meta.filter`, `meta.transclusion.tokenize` and
# `meta.transclusion.text-reference` each stand under both a block rule and an inline one. One
# specimen opening the block spelling therefore answers for both entries. The seven above read as
# seven ENTRIES across four distinct scope names, and no specimen can separate the pair.
#
# FOURTEEN STAND WHATEVER SENTINEL ARRIVES, and none of them wants one.
#
#   ITS END MATCHES WHERE ITS BEGIN DOES. The dash rules close inside their own line whatever a
#   reader feeds them (`ndash`, `mdash`); a filter-run prefix ends on a zero-width lookahead one
#   character along (two entries); a pretty link opens only where `[^\n]*\]\]` stands on the same
#   line; the script start tag ends `(>)|(?=^$)`. No cut anywhere can leave one open. Six entries.
#
#   IT CANNOT SPAN A LINE. A JavaScript `//` comment ends `\n` whatever the vendored grammar
#   spells, three entries' worth.
#
#   IT WANTS A CUT INSIDE A LINE. The two outer inline transclusion regions. This probe cuts at
#   line boundaries, so an inline construct always closes on the line that opened it. Two entries.
#
#   IT KEYS UNCLASSIFIED AND A KEY WOULD NAME THE WRONG CAUSE. A `<%if …%>` shortcut
#   (`meta.shortcut`, `meta.conditional.content`) and a `(((…)))` variable display
#   (`meta.filter.mvv-display`) each opened a region under a cut, and the kind vocabulary reads
#   innermost-first — the innermost region standing open under both is a `meta.filter.run` the
#   grammar RE-OPENS on whatever follows the cut. Its openness therefore carries no information
#   about which construct ran away, so a kind naming it would file two different causes under one
#   key and read like a classification. Three entries.
#
# THE CEILING STAYS AT 21 HERE. Lowering it means adding a specimen to `corpus/**`, and the count
# falls on its own the moment the sentinel stops colliding: 14 stands as the figure to compare
# against after that change lands.
#
# A region arriving with no specimen that opens it raises the count and fails the gate. That reads
# as the rule this whole battery exists to keep: a list nobody exercises cannot notice what it
# missed.
