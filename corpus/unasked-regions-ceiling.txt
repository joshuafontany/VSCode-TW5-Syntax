# Regions whose end can never break on a line, and that no cut in this corpus ever leaves open.
# The count may fall and may never rise.
#
# 98 regions carry no line bound. That number alarms and means little on its own: 36 of them stand
# open across a blank line under some cut and AGREE with the parser, because TiddlyWiki carries
# those constructs too — a `"""` attribute value spans blank lines, a definition body runs to its
# `\end`, an element with no closer reaches the end of the tiddler. Standing open names no defect.
# Disagreeing does, and the ledger beside this file holds all eight of those.
#
# What this count answers is COVERAGE. A region no specimen opens has not been found safe, only
# left unasked, and the difference reads the same from outside: a green gate. Measured with 800
# upstream TiddlyWiki tiddlers added to the sweep, twelve more regions come open — so this corpus
# under-covers its own grammar by a knowable amount, and the number below names the residue.
#
# THE COUNT ITSELF NEEDED A COLLIDE. It first read 118 and 79, because the reader looked for the
# bound by shape — `(?=^$)` or a trailing dollar — and a grammar spells the same bound five ways.
# Six inline emphasis rules ending `(?=$)`, whose begin refuses to open at all without a closer on
# the same line, sat among the runaways; so did the paragraph rule, which spells `^$` with no
# lookahead around it. Twenty regions were never unbounded, and seventeen of the residue were safe
# by construction. The reader now walks the pattern for a dollar standing as an ANCHOR, and a
# literal `\$` — which the widget rules and the typed block both carry — names no bound.
#
# The families in the residue, largest first: pragma directives, embedded language blocks, macro
# definition bodies, and the comment rules inside embedded JavaScript. Each wants a specimen that
# leaves it open at a line boundary, and each such specimen lowers this number by one.
#
# A region arriving with no specimen that opens it raises the count and fails the gate. That reads
# as the rule this whole battery exists to keep: a list nobody exercises cannot notice what it
# missed.
