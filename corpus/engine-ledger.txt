[\x00-\x1f]   # BEHAVIOUR — `syntaxes/tw5-fields.json`'s `invalid.illegal.field.name` lookahead, `(?=[\x00-\x1f])(.*)`. corpus/wikitext/tables.malformed.tw carries a literal tab beside a table cell's heading mark (the tab TiddlyWiki itself reads as text, never skipped the way a space is — table.js:83-95), and the JS translation of this control-character class reads the tab and matches from column 1 to end of line, where Oniguruma refuses the same class on the same line. Both engines still agree on every OTHER corpus line; this is the one construct — a bare control character inside a `text.html.tiddlywiki5.fields` line — where the translation and the WASM build part ways.
