# Whether a mark carries structure — findings from tools/ablation-witness.js.
#
# ablation-witness.js replaces each character the grammar claims as a delimiter, and each
# unclaimed non-word non-space character inside a construct TiddlyWiki built, with a neutral
# letter, re-parses in-process and asks whether the host's tree SHAPE changed.
#
#   <carrier>  <character>  <OVERREACH|MISS>  "<the line, trimmed>"  # reason
#
# OVERREACH  the grammar claims this character as a delimiter (punctuation.definition.*) and
#            ablating it leaves the host's tree shape unchanged — the grammar called it markup
#            and the host never needed it.
# MISS       the grammar leaves this character plain and ablating it changes the host's tree
#            shape — the host needed a mark the grammar left as ground.
#
# The key carries the line's TEXT rather than its number, so an edit elsewhere in a carrier moves
# nothing here, and an edit to the line itself asks for the judgement again.
#
# OWED marks a divergence standing as debt — a mark the grammar has not yet learned to test or
# paint, cited to the host rule that decides it. Every OWED line traces to a specific TiddlyWiki
# reading; none stands here on a guess.
#
# `node tools/ablation-witness.js --list` prints every finding in this form, keys derived.
