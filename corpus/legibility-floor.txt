# Of 65 bundled themes, how many tell each pair of constructs apart. Each count may rise and may
# never fall, and a pair carrying no line here FAILS until somebody seats it — a construct joining
# the list arrives unratcheted and says so rather than passing blind.
#
# ONE FLOOR ON THE WEAKEST PAIR READ GREEN THROUGH A LOSS ANYWHERE ELSE. Stripping a call of every
# name a theme rules on left the weakest pair — a code span against prose — exactly where it stood,
# and the gate held. The collision found that the day the gate stood up.
#
# THE READING MUST PAINT WHOLE CONSTRUCTS. Measured on CONTAINER scopes alone, a call, a filter run,
# a transclusion and prose each resolve to one colour across all 65 — no theme rule reaches
# `meta.variable.call.*` or `meta.transclusion.*`, so all four fall through to the default and 44 of
# 65 themes paint the containers identically. That reading says a reader meets four constructs in
# one ink; the whole-construct reading says every one of them parts from prose in all 65, because
# the distinction rides on the punctuation and name scopes inside. A floor seated on containers
# would rule a healthy grammar broken.
#
# THE `string.` FAMILY STANDS TAKEN. A wikilink wears `string.other.link.title` and a transclusion
# wears `string.text-reference`, so a third construct named into that family reads as those two in
# whatever theme rules on the family root. Measured: giving a code span `string.other` gained it 4
# themes against prose and cost it 8 against a transclusion and 2 against a wikilink. A raw span
# carries `markup.inline.raw.string` instead — the shape markdown, asciidoc and mediawiki share,
# under this grammar's own suffix — which gains 3 and costs nothing.
#
# WHICH OF THE FIVE HOLDS STRING CONTENT. `string` carried five constructs against 62 themes, and a
# theme ruling on the bare root paints every one of them alike. Read one at a time: a call and a
# widget each wear `string.quoted.double` on a QUOTED LITERAL, which the name states truly. A filter
# operand wears `string.entity.filter.operand` on the literal text between its brackets, also true —
# though the BRACKETS wear `string.punctuation.definition.operand.begin`, which seats a delimiter
# inside the string family rather than in `punctuation.definition` where every grammar writes one.
# Widening those two brackets moved NO pair of the seven specimens, so the misfiling stands reported
# and unchanged rather than shipped as a published surface no measurement asked for.
#
# The remaining two hold no string content at all. A wikilink's `string.other.link.title` names a
# link target, and markdown, asciidoc and mediawiki all seat a link title there — the same family-
# shape argument the raw span already answers to — so it stands. A transclusion's
# `string.text-reference` names what TiddlyWiki's parser assigns the INDIRECT kind: a name it
# dereferences against the store. That one reads string by inheritance and nothing else, and it
# carried the weakest pair in the table. Widened with `variable.other.reference` standing FIRST, a
# transclusion parts from a wikilink in 58 rather than 54 and NO OTHER PAIR MOVES. Traced before
# believing it: in `andromeeda` the rule `text.html string` painted `SomeTiddler` and `Some Title`
# one colour while `{{`, `}}`, `[[` and `]]` all fell to the default, so the two constructs reached
# a reader as one ink twice over.
#
# REACH BOUGHT BY MISNAMING BUYS NOTHING. `string.quoted.other` reads 58 against prose and calls a
# raw run a quoted one; `support.type.raw` reads 58 and calls it a type the framework provides.
# Both stand declined, the same ruling `keyword.control.list` drew at 100%.
#
# THE POPULATION COMES FROM THE HOST, AND ONLY THE NAMES ARE DECLARED. Seven specimens stood here
# by hand and the standing lesson answered: a hand-written enumeration cannot notice what it missed.
# It carried no emphasis at all, and emphasis holds the weakest readings in the whole table — a
# procedure definition against a macro definition at 0 of 65, subscript against superscript at 0,
# strikethrough against underline at 17. `$tw.modules.types.wikirule` names 44 rules TiddlyWiki
# stands and the harvest records that answer, so 40 constructs measure here and four leave the table
# by declaration: TiddlyWiki splits comment, filtered transclusion, call and transclusion by
# POSITION, block against inline, and a reader meets one thing either way. A rule the host adds
# arrives with no floor and says so.
#
# THE READING CARRIES fontStyle. A reader tells bold from italic without reading a word and most
# themes carry that in fontStyle alone: on foreground by itself bold parted from italic in 23 of 65,
# and a gate reading that way would have called a healthy grammar broken one family further along.
# Foreground and fontStyle together read 56. Two pairs seated under the older reading ROSE when it
# landed — a wikilink against prose from 61 to 65, and a code span against a wikilink from 59 to 65
# — because the underline a wikilink wears never showed in a foreground.
#
# A SPECIMEN CARRIES NO TRAILING NEWLINE. One splits into an empty last line, and vscode-textmate
# hands an empty line a token of width 1 standing in front of the newline — base scope, no character
# painted. Flattened into the reading it adds the DEFAULT colour to every specimen and collapses
# distinctions that stand: on `snazzy-light` a filter run and a transclusion each painted #ADB1C2
# and #CF9C00, the filter run alone carried an unpainted space, and the phantom handed the
# transclusion that third look for free. The pair read 63 without it and 62 with. A zero-width
# filter does not catch it — the token measures one character wide — and not asking for the line
# does.
