# Where the two readers part at a block boundary, and what this repo ruled about each.
#
# tools/swallow-witness.js cuts every corpus file at every line, appends a blank line and a
# sentinel quoteblock, and asks TiddlyWiki and the grammar the same question about the same
# offset. A line here names a divergence already looked at; anything else fails the gate.
#
#   <direction> <key>   # reason
#
# `runaway`   the parser reads the sentinel and the grammar does not — the grammar holds a region
#             open across a boundary the parser closes.
# `overbound` the grammar reads the sentinel and the parser does not — the grammar closes a region
#             the parser carries.
#
# The key names the scope the grammar had open (runaway) or the rule TiddlyWiki had open
# (overbound); `*` stands for any run of characters. A reason opening OWED records a divergence
# rather than accepting it: the gate stays green and prints it as debt.
#
# A REASON CARRIES MEASUREMENTS, NEVER A REMEDY IT HAS NOT COLLIDED. Two traps sit under that
# rule. A ruling that calls a divergence unfixable wants its cost counted on BOTH sides — the bound
# on start tags looks expensive and costs nothing, since no plain HTML start tag in 2583 files
# carries a blank line. And a remedy that reads obvious may prove unwritable: vscode-textmate
# hands a pattern one line and no more, so an end pattern standing at a blank line cannot read the
# line that decides the question. A remedy nobody tried reads as work owed, and sends the next
# reader to build what will not build.
#
# A RULING THAT EXPLAINS NOTHING FAILS THE GATE. A divergence gets fixed and its line stays, and
# the ledger then reads as a longer list of standing debt than the repository carries.

# ── the lookahead the parser has and a grammar cannot ────────────────────────────────────────
# Each of these turns on text TiddlyWiki reads BEYOND the construct, sometimes to the end of the
# source. A TextMate end pattern reads only forward from the line in front of it, one line at a
# time, and carries no way to ask whether a closer stands anywhere later. Where the parser's
# answer depends on that lookahead, the grammar carries the region — the reading that holds for
# the terminated form — the form nearly all real text takes.

runaway comment.*        # `<!--` with no `-->`: measured, TiddlyWiki carries a comment across every blank line between when a closer stands later in the source, and refuses the construct outright when none does. Carrying reads the terminated form right
runaway meta.embedded.*  # `<style>` and `<script>` with no closer: TiddlyWiki carries the element to the end of the tiddler — its own `unterminated-html` hint says so — and parses the body as WIKITEXT BLOCKS. Both readers carry; only the language of the interior differs, and CSS and JS there hold the convention every HTML grammar keeps
runaway meta.element.*              # an SVG or MathML element reads the same way, for the same reason
runaway meta.tag.widget.*           # a quoted attribute value left open inside a widget tag: TiddlyWiki refuses the whole tag where no closing quote stands anywhere, and builds the element across the line break where one does. A value spanning lines reads normally — of eleven accepted start tags carrying a blank line, eight carry it inside a quoted value — so the string region carries on, and the reading holds for every value that closes
runaway meta.directive.variable.*   # a pragma signature left open: a `\define` or `\parameters` whose closing `)` stands on a later line, cut where the reader sits inside it. Measured at pragmas.signatures.tw:1, and at 3, 4 and 5 — one cut per default quoting the grammar carries a region for. TiddlyWiki refuses the definition outright where the signature closes nowhere ahead, and builds it across every blank line where the closer stands somewhere later; a definition body runs to `\end` the same way. The forward arm moves the parser's verdict on all four cuts, and the control — trailing nonsense in place of the file's own text — moves nothing, so the deciding evidence sits past what any pattern reads. Handing back the closing `)` alone moves it too, which names the evidence exactly. So the grammar carries the region, the reading that holds for every signature that closes


# ── recorded, not accepted ───────────────────────────────────────────────────────────────────

runaway meta.transclusion.*         # `{{A/Tiddler||A` left open: TiddlyWiki refuses the transclusion and parses the block after the blank line, and the grammar carries the region. tools/light-cone.js moves the parser's verdict by handing back the text the cut removed, so the decision turns on a closer standing further down the source than any pattern reads
overbound html                      # OWED — an element with no closer: TiddlyWiki carries it to the end of the tiddler and says so in its own hint, and reads the body as one inline run where no blank line follows the tag. The grammar opens no region over a block element's body at all — it colours the two tags and hands what lies between to the block rules, which tests/tiddlywiki5/tiddlywiki5.widget-body.tw5.test pins for the one-line form — so the text after an unclosed tag reads as ordinary blocks rather than as that element's content
overbound codeblock                 # OWED — an unterminated fence takes the rest of the source in TiddlyWiki; the grammar ends it at the blank line

overbound (nothing)   # a cut standing inside a `\define` body, where the parser holds no rule at all. Measured at definitions.forms.tw:1: TiddlyWiki stores a macro body VERBATIM and never parses it, so the whole cut reads as one `set/macrodef` node with nothing inside, while the grammar paints wikitext in there on purpose — `tw5-substitution-injection.json` injects on `meta.variable.macro.body`, and `$param$` substitutes there and nowhere else. The two readers answer different questions rather than the same one differently. Reading offsets in ONE coordinate space surfaced this: a nested parse restarts offsets at zero, and an inner node read as standing in the document had been covering the cut and answering for a rule the parser never held there
