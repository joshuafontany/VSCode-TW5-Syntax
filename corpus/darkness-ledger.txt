# Where TiddlyWiki builds a construct and the grammar answers with nothing of its own.
#
# tools/darkness-witness.js reads every wikitext carrier under both readers and judges each line
# of each construct the host builds. A line here names darkness already looked at; any other dark
# line fails the gate, and a line here that reads lit fails as stale — so a repair retires the debt
# it paid, and a declaration cannot outlive what it explains.
#
#   <carrier>  <rule>  <MISS|LOST>  "<the line, trimmed>"  # reason
#
# MISS  the grammar reads nothing of the line even with the construct standing alone — no rule
# LOST  it reads the construct alone and loses the line in place — text above holds a region
#
# The key carries the line's TEXT rather than its number, so an edit elsewhere in a carrier moves
# nothing here, and an edit to the line itself asks for the judgement again.
#
# OWED marks a divergence standing as debt. A line reading dark on purpose carries its ruling
# instead, and says why a reader should meet plain text where the host builds markup.
#
# `node tools/darkness-witness.js --list` prints every dark line in this form, keys derived.
#
# A reason opening `READER <version>` (tools/reader-scope.js) answers for ONE reader alone — the
# version `tw5-oracle.js` boots against, read off `$tw.version`. A line naming no reader answers to
# whichever reader reads it; one naming a reader neither fails nor reads stale under the other.
