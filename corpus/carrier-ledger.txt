# Divergences the carrier ground surfaces, which this corpus holds no specimen for.
#
# `tools/still.js` passes over ground outside this repository — the memetic carriers — and asks
# whether any divergence class stands unnamed. A class named here says the base held and the ground
# merely widened; a class named nowhere says the base still moves.
#
# HELD APART FROM `swallow-ledger.txt` ON PURPOSE. That one rules what this corpus produces, and a
# ruling there explaining nothing fails its gate — rightly, since a corpus ruling with no corpus
# specimen has outlived its cause. A carrier class has no corpus specimen BY CONSTRUCTION, so it
# needs a ledger whose entries answer to different ground.
#
#   <direction> <key>   # reason
#
# A reason opening OWED records a divergence rather than accepting it.

runaway meta.codeblock.*   # a fenced block whose readers part on the SECOND fence. Measured: a fence CONTINUING A PARAGRAPH reads as codeinline to the parser and opens nothing in the grammar — both agree there — and from that point the two pair the remaining backtick runs differently, so a later fence at a block start opens for one reader and not the other. tools/light-cone.js moves the verdict on BOTH arms: returning the text after the cut, and striking the first fence. The evidence sits outside the grammar's reach in both directions, so no pattern reaches it and the parser stays canonical without the grammar being able to follow

runaway meta.variable.call.*   # a quoted parameter value left open. Measured: TiddlyWiki carries a quoted parameter across a BLANK line and builds the call — one newline or many — and refuses the call only where the closing quote stands nowhere in the source. So the string region cannot take a blank-line bound without cutting what the parser carries, and the call's own bound never fires while that child region sits on the stack (the region publishes meta.variable.macrocallblock beside this name). tools/light-cone.js moves the verdict on the forward arm: returning the closer changes it. Reproduced at api/memetic-wikitext-sensorium.mem:77, one line. NO BLANK-LINE BOUND ANSWERS THIS: TiddlyWiki builds a call wherever `>>` stands ahead anywhere in the source and builds nothing where none does, and one line of lookahead cannot tell those apart. Measured over 700 carriers and 16087 openers: 116 close on a LATER line, which a bound would cut, and NONE lack a closer entirely, which is the only case a bound would help. The same fault opening INSIDE PROSE reads the same key: `tools/region-kind.js` names the region a cut leaves open by kind, innermost-first, so a call keys as a call whether it opens a block or stands mid-paragraph. Reproduced there too, at docs/relational-parameter.mem:129, where a cut lands mid-line inside an inline code span

runaway meta.embedded.*   # a tiddler whose header declares a type that hands the body to another grammar. Measured at sdm/procedures/tag-pill-styles.tid, `type: text/css`: TiddlyWiki parses the body as text/css and builds ONE `genesis` node covering it with no structure inside, where the same body under text/vnd.tiddlywiki builds `element/parseblock`. So the grammar opens `meta.embedded.block.css` on the header's declaration and hands the body to source.css, and no wikitext node stands inside it for any region to answer to — the region reads as runaway wherever a cut leaves the body short of what the declaration promised. Permanent by construction: the divergence names the embedding working, and closing the region would take the body away from the grammar the header names


overbound (nothing)   # a cut standing inside a `\define` body, where the parser holds no rule at all. Measured over TiddlyWiki's own tiddlers at es-ES/$__editions_tw5.com_wikitext-macros.tid:27: the whole cut parses to ONE `set/macrodef` node and nothing inside it, because TiddlyWiki stores a macro body verbatim and never parses it. The grammar paints wikitext in there on purpose — `tw5-substitution-injection.json` injects on `meta.variable.macro.body` and `$param$` substitutes there and nowhere else — so the two readers answer different questions rather than the same one differently. Permanent by construction: closing the region would take a body the host renders as wikitext away from the grammar that renders it

overbound typedblock   # a cut inside a typed block that declares wikitext. Measured at es-ES/$__editions_tw5.com_wikitext-macros.tid:18, `$$$text/vnd.tiddlywiki>text/html`: TiddlyWiki parses the body as the type it declares and the nodes that parse builds carry offsets into the INNER text — the block reports 23..42 and a quoteblock inside it 0..14 — so no node of that inner parse stands in the document's own coordinate space. `flatten(tree, { sameSpace: true })` keeps every offset reading inside one space rather than reading an inner node as standing at the top of the document, and what remains covering the cut reads `typedblock`. The grammar paints the inner content in place, which is what the declaration asks for. Permanent by construction: the two readers answer in different coordinate spaces rather than answering the same question differently

runaway meta.directive.variable.*   # a definition block runs to `\end`, across blank lines and all: measured, a `\define` body spans them freely when the terminator stands somewhere later, and keeps to its opening line when none does anywhere. Held here rather than beside the corpus rulings: no corpus cut reads this way once every offset reading stays in ONE coordinate space, and a ruling with no specimen fails the corpus gate by design. TiddlyWiki's own tiddlers carry it, which is the ground this ledger answers to
