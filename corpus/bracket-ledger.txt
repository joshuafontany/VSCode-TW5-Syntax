# Every bracket VS Code paints red in a carrier, and why.
#
# tools/bracket-witness.js reads each carrier as the editor does — the pairs its language
# configuration names in `brackets`, matched only inside tokens vscode-textmate types Other — and
# every red it finds stands here. An undeclared red fails the gate, and a declaration whose bracket
# reads matched fails as stale, so a repair retires the line it paid.
#
#   <carrier>  <column>  <bracket>  <open|close>  "<the line>"  # reason
#
# The key carries the line's TEXT rather than its number, so an edit elsewhere in a carrier moves
# nothing here. Most reds below tell the truth: the carrier holds a bracket TiddlyWiki too reads as
# unmatched, on purpose, to show what the host does with it. OWED marks a red the grammar or the
# carrier owes. A degenerate carrier's reds stand counted by the gate rather than declared.
