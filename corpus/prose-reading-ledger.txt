# Scopes a theme's rule REACHES and leaves reading as ordinary prose, and the reason each stands.
#
# `theme-paint` answers whether a theme's rule reaches a scope. A rule can reach and set the colour
# the editor already had, and then a reader meets body text however loudly every coverage gauge agrees
# a theme found the construct. Derived over the 65 bundled themes: 1,191 of 11,756 foreground rules —
# one in ten — paint the editor's own foreground.
#
# HELD APART FROM `PlainConstructs`, WHICH RULES THE OTHER FAULT. That one rules a construct NO rule
# reaches; this one rules a construct a rule reaches and buys nothing for. The two cures differ — the
# first wants a name themes rule on, the second wants a DIFFERENT family — and a list fusing them
# sends a reader to the wrong repair.
#
# The bar stands at a quarter of the bundled set. Below it the reading names a habit every grammar
# shares: our widget's `<` reads as prose in 18 of 65 themes and the real `html` grammar's own `<`
# reads as prose in exactly 18 too.
#
#   <scope>   # the reason it stands
#
# THE FAMILY CEILING, measured. Every `variable.*` spelling resolves through `variable` in the themes
# that rule on the root, so all six of the grammar's variable-family names read identically: 58 of 65
# themes reach them and 22 of those 58 leave the colour where the editor had it. `variable` is the
# single most-shipped leave-it-alone selector in the bundled set — 18 of the 54 themes ruling on it
# change nothing. No truthful rename escapes it: every `support.other.*` spelling measures 20 of 65
# invisible, and the three loud alternatives — `support.class`, `support.type`, `support.function` —
# buy their colour by naming these things something they are not. A call's name took
# `support.function.macro` because a macro IS a function the wiki provides; nothing here is a class or
# a type, so nothing here follows it. The names below stand as the honest reading of a real ceiling.

variable.entity.filter.operand   # a filter step's operand, which the `variable` family names honestly and no louder family names truthfully
variable.name.mvv.attribute      # an attribute bound to a multi-valued variable — a variable, and the family ceiling above holds
variable.name.mvv.default        # a parameter's multi-valued default, the same reading
variable.name.mvv-display        # an `((mvv))` display run, the same reading
variable.name.substitute-variable  # a `$(name)$` substitution inside a definition body, the same reading

# A VOCABULARY NO THEME AUTHOR RULES ON. `markup.superscript` and `markup.subscript` reach only 9 of
# 65 themes at all, and markdown's own `markup.superscript` measures the same 2 of 65 paint rate this
# grammar does — so the name matches the flagship exactly and the silence belongs to the vocabulary,
# not to this grammar. A louder family would part these two runs from every other markup construct a
# theme paints as a family.
markup.superscript               # the conventional name, unthemed across the bundled set, matching markdown's own reading
markup.subscript                 # the same reading
