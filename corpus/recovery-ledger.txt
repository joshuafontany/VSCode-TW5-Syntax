# Where TiddlyWiki recovers out loud and the grammar shows a reader nothing.
#
# `WikiParser.addDiagnostic` normalises {from, to, severity, source, code, message}, and seventeen
# wiki rules raise one when a construct never closes. `tools/recovery-witness.js` parses every
# carrier, takes the host's diagnostics, and asks what the grammar puts across the same span.
#
#   silent <code>   # <reason> · ceiling: <ceiling key>
#
# A SILENT CODE NAMES A FINDING, never a defect on its own. A line-local pattern cannot know that a
# closer never arrives anywhere ahead, so these sit behind a ceiling this repository already
# measured. Every ruling MUST name the ceiling that answers it — a ruling naming none hands the
# language server nothing, and `tools/recovery-witness.test.js` fails on one.
#
# THE POPULATION COMES FROM THE HOST, so a code nothing here raises yet reaches this file the day a
# carrier raises it, and a ruling outliving what it explains fails the same gate.
#
# A BLOCK CONSTRUCT THAT NEVER CLOSES SWALLOWS EVERY RECOVERY AFTER IT. One carrier measures the
# first unterminated block shape it holds and hides the rest, which is why the degenerate carriers
# stand apart — `degenerate.unterminated.tw` holds the inline runs, and each block shape takes a
# carrier of its own. Six block shapes each hold one, and every `unterminated-*` code the host's
# wiki rules declare now reaches a ruling below; `tools/recovery-witness.test.js` reads that
# population out of the host's own rule sources, WALKING THEM, because six of the sixteen live
# under `rules/emphasis/` and a flat read finds ten and goes quiet about the rest.
#
# Measured over 673 host carriers: 34 diagnostics, 7 codes, and the grammar marks ZERO of them.
