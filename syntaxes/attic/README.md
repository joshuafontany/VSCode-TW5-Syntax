# Attic

Grammars set aside, kept whole, and out of the manifest.

A file here stands readable and unloaded. Nothing in `package.json` names it, no gate reads it, and
no editor opens under it. It stays because a rewrite that discards its source discards the
measurements that justified the rewrite.

| file | why it stands here |
|---|---|
| `memetic-wikitext.sketch.json` | Measured over 677 carriers, the sketch REPLACED rather than added: not one of its nineteen rules carries a base scope forward, and six of seven memetic constructs lose every base scope they stand on — 44 996 spans across 191 scopes, headed by the hex entity reading of a carrier control code and the `tw-<name>` reading of every sigil parameter. Three rules stand on ground wikitext never names, and those seed the grammar that replaces it: `lar-uri`, `fragment`, `bearing`. The `L:` injection block it carries names the composition the replacement adopts. |
